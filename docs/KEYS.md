# Keys

| Key | Action | Pane |
|---|---|---|
| `j` / `k` | next / previous item | list, sources |
| `gg` / `G` | first / last | list |
| `o` / `Enter` | open article | list |
| `v` | reader view: the full article from its page, or back to the feed's summary | list, article |
| `O` | open in browser | list, article |
| `m` | toggle read | list |
| `M` | mark folder read | sources |
| `s` | star | list, article |
| `y` | copy link | list, article |
| `/` | search | any |
| `r` | refresh selected source; `R` all | any |
| `u` | unread only; `S` starred; `t` today | any |
| `a` | add sources (the catalog) | any |
| `Tab` / `Shift-Tab` | next / previous pane | any |
| `1` `2` `3` | toggle sources / list / article pane | any |
| `:` | command palette | any |
| `?` | help | any |
| `q` | quit | any |

## Add sources screen

Shown on first run, when the store has no sources, and opened with `a`.

| Key | Action |
|---|---|
| `j` / `k` / `↓` / `↑` | next / previous row |
| `l` / `h` / `→` / `←` | next / previous category |
| `Tab` / `Shift-Tab` | next / previous category |
| `Space` | check or uncheck the feed under the cursor |
| `a` | check every feed in the category, or uncheck them all |
| `Enter` | add the checked feeds |
| `Esc` | close without adding |
| `q` | quit |
