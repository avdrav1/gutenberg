# Keys

| Key | Action | Pane |
|---|---|---|
| `j` / `k` | next / previous item | list, sources |
| `gg` / `G` | first / last | list |
| `o` / `Enter` | open article | list |
| `O` | open in browser | list, article |
| `m` | toggle read | list |
| `M` | mark folder read | sources |
| `s` | star | list, article |
| `y` | copy link | list, article |
| `/` | search | any |
| `r` | refresh selected source; `R` all | any |
| `u` | unread only; `S` starred; `t` today | any |
| `a` | add source | any |
| `Tab` / `Shift-Tab` | next / previous pane | any |
| `1` `2` `3` | toggle sources / list / article pane | any |
| `:` | command palette | any |
| `?` | help | any |
| `q` | quit | any |
